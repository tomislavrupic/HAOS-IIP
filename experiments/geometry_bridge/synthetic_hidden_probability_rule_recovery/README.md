# Synthetic Hidden Probability Rule Recovery

This benchmark tests whether a frozen observer can recover a hidden
probability rule from concealed transformation-conditioned observations.

Targets:

- normalized probability model
- holdout outcome prediction
- calibration
- null-rule rejection
- transformation-conditioned generalization
- no target leakage
- reproducibility

Current state: `OPEN`.

It is synthetic calibration only and does not authorize Bell or physical
mechanism claims.
