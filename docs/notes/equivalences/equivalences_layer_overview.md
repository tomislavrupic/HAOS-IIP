# Equivalences Layer Overview

The equivalences layer records deliberately scoped structural correspondences inside frozen discrete operator regimes.
It is a documentation layer, not a physics bridge.

## Purpose

This folder exists to make a few mathematically nearby correspondences explicit without turning them into ontological claims.
The notes are meant to be readable, auditable, and easy to compare against the repo's frozen operator language.

## Current notes

1. **Spectral Address and Laplacian Eigenmodes**
   - spectral address as a recoverable eigenmode identity coordinate
   - nearby language: Laplacian eigenmodes, spectral clusters, harmonic identity

2. **Current Closure and Discrete Conservation Balance**
   - current closure as a bounded flux-like or divergence-like balance
   - nearby language: discrete conservation, flux balance, exact / coexact bookkeeping

3. **Hodge Decomposition and Discrete Sector Splitting**
   - exact / coexact / harmonic sector split as a Hodge-style decomposition
   - nearby language: cochain complexes, Laplacians, harmonic remainder

## Rules

- Stay inside frozen discrete/operator regimes.
- State a clear claim ceiling in every note.
- Add evidence gates or failure conditions.
- Use structural equivalence or analogy language only when that is the strongest supported reading.
- Do not reopen Bell, hydrogen, or other frozen physics bridges.
