# HAOS-IIP Bridge Extraction

This folder contains extracted, HAOS-IIP-facing material from the PDF corpus.

The extraction is deliberately selective:

- keep concepts that can sharpen HAOS-IIP bridge work
- keep operational diagnostics and failure warnings
- avoid copying full paper text into the repository
- avoid treating literature adjacency as physical validation

## Files

- `pdf_extraction_manifest.csv` - machine-generated extraction status and
  keyword counts for all PDFs.
- `pdf_extraction_manifest.json` - same information in JSON form.
- `haos_iip_bridge_extraction.md` - distilled concepts and mappings needed for
  HAOS-IIP bridge work.
- `bridge_methods_spine.md` - method-facing bridge toolkit extracted from the
  corpus.
- `bridge_action_items.md` - concrete next bridge uses.

## Extraction status

All 47 PDFs in the corpus produced extractable text.

## Boundary

This folder extracts bridge ingredients.
It does not establish a physical bridge.
