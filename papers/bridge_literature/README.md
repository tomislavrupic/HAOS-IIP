# HAOS-IIP Bridge Literature

This folder is a curated reading pack for the parts of HAOS-IIP that touch
spectral structure, Hodge theory, curvature, transport, and physics-flavored
bridge language.

It is not a proof of correspondence. It is a map of the literature that is
most relevant to the current bridge stack.

## Contents

- [External bibliography](sources.md)
- [Repo-local bridge papers](local_bridge_papers.md)

## Reading intent

Start here if you want the shortest route through the bridge landscape:

1. spectral clustering / graph Laplacians
2. Hodge decomposition / Laplacians on cochains
3. curvature on graphs and transport geometry
4. optimal transport and kernel distances
5. lattice / Dirac-Kähler / discretized field-theory analogies
