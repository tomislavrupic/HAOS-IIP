# Speculative Bridge

This folder is playground mode.

Everything here is explicitly exploratory, analogy-seeking, and non-binding.
Nothing in this folder changes the frozen synthetic core, the claim-gating
rules, or the verified bridge boundaries.

Use this space to ask "what if this resonates with reality?" without treating
the answer as established.

## Rules

- Keep the frozen core untouched.
- Label every note as speculation, analogy, or exploratory mapping.
- Do not treat these notes as evidence of physical correspondence.
- If a mapping feels promising, it still needs a real frozen test elsewhere.
