# Phase XIX Spectral Address

Phase XIX is a terminology and translation phase.

It re-frames the older internal phrase "harmonic address" as the stricter technical term "spectral address":

```text
A spectral address is a coordinate that identifies a stable, recoverable resonance pattern inside a discrete interaction-invariant system.
```

This phase consumes frozen HAOS-IIP artifacts and canonical terminology only. It does not run new dynamics, alter frozen manifests, or promote any physical ontology.

Run:

```bash
python3 phase19-spectral-address/build_spectral_address.py
```

Check:

```bash
python3 phase19-spectral-address/diagnostics/check_phase19_bundle.py
```

Artifacts:

- `spectral_address_definition.md`
- `slide_alignment.md`
- `phase19_summary.md`
- `phase19_manifest.json`
- `runs/phase19_runs.json`
